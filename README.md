Code and data for the paper "A Dual\-Path Model for Developing Trust in Generative Artificial Intelligence."

## Code

- 20260912final_code.Rmd: Code for all analyses reported in the paper.

## Study 1

- mediationdata.xlsx: Data for Study 1, used for the mediation analysis.

## Study 2

- experiment.xlsx: Pre-test and post-test data, used to compare changes in trust among the increased-CT, non-increased-CT, and control groups.
- experiment_logfile.xlsx: Summary of coded behaviors across all rounds for each participant, used to compare the proportions of different behavior types between the increased-CT and non-increased-CT groups.
- experiment_2step.xlsx: Temporally ordered behavior for each participant, used to construct two-step behavioral sequences and compare the proportions of different sequences between the increased-CT and non-increased-CT groups.
- coding_all.xlsx: Coding results for all participant inputs, used to assess inter-coder reliability.

## Study 3

- sliding_windows.xlsx: Data for Study 3, used to examine temporal patterns in trust development and mediation effects, as well as the condition specificity of these patterns.
